# 로컬 메모리 트리

> 엘리자베스가 장기 맥락을 Obsidian 호환 Markdown으로 정리하는 공간입니다.

## 원칙

- 모든 파일은 로컬 Markdown으로 저장한다.
- 민감 정보, 비밀번호, 토큰은 저장하지 않는다.
- 하이머딩거 실행/운영 기록은 `hermes저장소/하이머딩거`와 섞지 않는다.
- Hermes 기본 memory에는 짧은 핵심만, 자세한 맥락은 이 트리에 남긴다.
- 대화 전체 원문 저장보다 **요약된 장기 기억**을 우선한다.

## 구조

- [[profile/preferences|preferences]]: 사용자 선호
- [[profile/routines|routines]]: 반복 루틴과 자동화 선호
- [[profile/environment|environment]]: 현재 로컬 환경과 경로
- [[profile/boundaries|boundaries]]: 접근/수정/보안 경계
- [[daily/2026-05-29|daily]]: 날짜별 요약 기록
- [[projects/index|projects]]: 프로젝트별 맥락 인덱스
- [[decisions/2026-05|decisions]]: 결정 사항 로그
- [[inbox|inbox]]: 아직 분류하지 않은 기억 후보
- [[_system/로컬 메모리 시스템 v1|로컬 메모리 시스템 v1]]: SQLite 인덱스/검색/압축 운영 문서
- [[Dataview 링크 점검]]: 로컬 메모리 위키링크/백링크 점검 대시보드

## 사용법

1. 사용자가 “기억해”, “기록해”, “정리해”라고 말하면 적절한 파일에 짧게 반영한다.
2. 다음 대화에서 맥락이 필요하면 이 폴더를 먼저 검색한다.
3. 확실하지 않은 내용은 `inbox.md`에 임시 기록하거나 사용자에게 확인한다.
